请求示例

# 读取主题列表
curl -H "Authorization: Bearer $ZHIJI_TOKEN" \
  {{ request.scheme }}://{{ request.get_host }}/api/v1/topics/
# 查询包含关键词的笔记
curl -H "Authorization: Bearer $ZHIJI_TOKEN" \
  "{{ request.scheme }}://{{ request.get_host }}/api/v1/entries/?q=ORM&limit=20"
# 快速写入一条笔记
curl -X POST -H "Authorization: Bearer $ZHIJI_TOKEN" \
  -d "topic_name=速记" -d "text=今天的收获" \
  {{ request.scheme }}://{{ request.get_host }}/api/v1/entries/create/
# v2：分页读取笔记
curl -H "Authorization: Bearer $ZHIJI_TOKEN" \
  "{{ request.scheme }}://{{ request.get_host }}/api/v2/entries/?page=2&page_size=10"
# v2：写入一条笔记（JSON）
curl -X POST -H "Authorization: Bearer $ZHIJI_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"text":"今天的收获","topic":1}' \
  {{ request.scheme }}://{{ request.get_host }}/api/v2/entries/

返回结构

{
  "ok": true,
  "count": 2,
  "results": [
    {"id": 1, "text": "Django ORM", "progress": 40}
  ]
}

v1 出错时返回 {"ok": false, "error": "..."}；v2 统一为 {"error": {"code": 400, "message": "..."}}。

安全约定

只返回自己的数据 令牌与用户绑定，越权一律 404
令牌只明文出现一次 页面仅展示掩码，请自行保存
吊销立即生效 不需要等待缓存过期
